# Repository Guidelines

Contributor guide for **pi-sync**, a shell-script repo that backs up and restores pi (1.4.0) core configuration.

## Project Structure & Module Organization

```
backup.sh          # rsync local pi config → config/, then git commit + push
restore.sh         # git pull → overwrite managed paths → pi install packages
config/            # snapshot of pi configuration (the actual "data")
  settings.json    #   ~/.pi/agent/settings.json
  mcp/mcp.json     #   ~/.config/mcp/mcp.json
  skills/          #   ~/.agents/skills/ (lark-* excluded)
  AGENTS.md, SYSTEM.md, APPEND_SYSTEM.md, keybindings.json
  extensions/, prompts/, themes/
README.md          # usage and restore instructions
```

There is no source code or test directory; the scripts plus `config/` are the whole project.

## Build, Test, and Development Commands

- `./backup.sh` — sync config into `config/`, commit, and push. Exits early with `无变更，跳过提交` when nothing changed.
- `./restore.sh` — pull, overwrite managed paths, reinstall extensions from `settings.json`.
- `git status --short` — verify a script run left a clean tree.

## Coding Style & Naming Conventions

- POSIX `sh` (`#!/bin/sh`), 2-space indentation, no bashisms.
- Start with `set -eu`; use `REPO`/`CFG`-style uppercase variables.
- Keep comments in Chinese, matching existing scripts.
- No linters or formatters are configured; match the surrounding style.

## Testing Guidelines

No test framework. Manually verify changes: run the affected script, then confirm `git status --short` is empty and `git log -1` shows the expected commit.

## Commit & Pull Request Guidelines

- Automated commits: `backup: YYYY-MM-DD HH:MM:SS` (generated by `backup.sh`; do not hand-edit).
- Manual commits: short imperative summaries (e.g. `排除 lark-* 技能，不再入库`); Chinese is fine.
- PRs: describe which script paths changed, include the verification output (`git status`, `git log -1`), and note any change to managed/excluded paths.

## Security & Configuration Tips

- Never commit credentials: `auth.json`, `sessions/`, `npm/`, `models-store.json`, and `mcp-cache.json` are excluded — keep it that way.
- `restore.sh` **force-overwrites** managed paths (`rsync --delete` on `skills/` and `extensions/`); warn reviewers of any path added to that list.
- `lark-*` skills are intentionally excluded from sync; do not remove those `--exclude` flags.
